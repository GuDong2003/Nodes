# Scope

- Authorization: user confirmed `已授权` in the active session.
- In scope: the user's Nodes deployment, its self-hosted mail integration, and
  the ProxyScrape registration/onboarding workflow.
- Network profile: authenticated maintenance over SSH and HTTPS API validation.
- Excluded: paid checkout, unrelated hosts, destructive actions, and disclosure
  of credentials, access tokens, mailbox data, or exported proxy credentials.
